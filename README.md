Project Name:
Alzikrayat – Photo Sharing Web Application

Project Description:
Alzikrayat is a full-stack photo-sharing web application developed using the MERN Stack. The application allows users to create accounts, log in securely, upload and share photos, and explore photos shared by other users.

Users can add titles and descriptions to their photos, browse the photo gallery, view photo details, and interact with shared photos through comments.

The application provides a user-friendly interface and uses a RESTful API to connect the frontend with the backend.

How to Run:
1. Download or clone the project repository.
2. Open the project folder.
3. Configure the required environment variables in the `server/.env` file.
4. Make sure MongoDB is running and the database connection is configured correctly.
5. Open a terminal inside the `server` folder and install the dependencies:

   `npm install`

6. Start the backend server:

   `npm run dev`

7. Open another terminal inside the `client` folder and install the dependencies:

   `npm install`

8. Start the frontend application:

   `npm run dev`

9. Open the local development URL displayed in the terminal in your browser.
